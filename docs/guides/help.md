## Overview

`prefix+?` in tmux opens a fuzzy picker over the generated
`docs/INDEX.md`: every tmux bind, zsh alias and function, script, Claude
skill, TUI, doc and decision the personal workflow provides, each with the
file and line it comes from. Use it when you half-remember a binding or
want to see where something is defined. It is plain fzf over the INDEX, so
no Claude session is involved and it opens instantly.

There used to be a `/help` Claude skill that answered questions from the
same INDEX. It was removed on 2026-11-14 after zero uses, and the name
clashed with Claude Code's own `/help`. For a question that needs
reasoning ("why do I have X bound"), open a quick-ask window with
`prefix+q` and ask Claude to look it up in `~/code/dotfiles/docs/INDEX.md`.

## Try it now

1. Press `prefix+?`. A new tmux window opens with the picker.
2. Type `wb picker`. The `prefix+m` bind comes up, and the preview shows
   its line in `tmux.conf` with five lines of comment either side.
3. Press Enter. The source opens in nvim at that line, in its own window.

## Reference

| Entry kind | Preview shows | Enter does |
|---|---|---|
| bind, alias, function, script | The source line, marked, with 5 lines either side | Opens nvim at that line |
| skill | The skill's description and its "When to use" section | Opens the `SKILL.md` in nvim |
| doc, guide | The first 40 lines of the source | Opens the rendered HTML page in the browser (when one exists) |
| decision | The title and options list | Opens the decision file in nvim |

- A query typed after the command pre-fills the search:
  `~/.config/scripts/tmux/help.sh wb` opens the picker already filtered.
- The picker never runs the thing it shows. The INDEX's `invoke` column
  says how to run it.

## Known rough edges

- **Only as current as the last rebuild.** The INDEX is generated by
  `docgen.sh index`, so something added since the last run won't show up
  until the next one.
- **Employer-repo content is left out** of the personal INDEX on purpose.
- **Shadows tmux's own `prefix+?`** (list-keys). The INDEX carries the
  tmux binds too, with their comments.

## Next steps / reverting

- Source: `scripts/.config/scripts/tmux/help.sh`; bound in
  `tmux/.config/tmux/tmux.conf` (`bind ? new-window …`).
- To get tmux's list-keys back, delete the `bind ?` line and reload tmux.
