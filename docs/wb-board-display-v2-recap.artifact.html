04 Try it yourself

cd ~/code/dotfiles   # or this worktree
wb board --html
xdg-open logs/board.html

Things to look for: Pipeline is the default tab and lists every non-done task regardless of window. A done task's detail card has the same two-zone layout and stepper as an in-flight one. The Repo/Family dropdowns narrow every tab's rows at once — but never Key Findings, which stays board-wide on purpose.
